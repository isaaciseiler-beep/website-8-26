# Satoshi webfonts

Unmodified WOFF2 files retrieved November 4, 2026 from the official Fontshare CSS API for Satoshi 300, 400, 500, and 700:

`https://api.fontshare.com/v2/css?f[]=satoshi@400,500,700&display=swap`

The 300 face was retrieved separately with `f[]=satoshi@300` to preserve existing light-weight consumers; it is loaded on demand.

The vendor's ITF Free Font License v2.0 permits self-hosting for the licensee's own websites. The complete vendor notice is retained in `ITF-FFL.txt`; the current original is at https://www.fontshare.com/licenses/itf-ffl.

These files are for this portfolio's web use. Do not modify, subset, convert, or redistribute them as a font library or template asset. No 600 face exists in the retrieved vendor stylesheet; CSS matching continues to use the available weights rather than declaring a fictitious face.
